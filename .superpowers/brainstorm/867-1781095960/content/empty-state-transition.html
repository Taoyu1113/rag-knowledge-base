空状态 → 对话：如何过渡？

学生打开页面看到欢迎语。发送第一条消息后，欢迎语消失，对话流开始。这个过渡怎么做？
上次实现中，Overlay 方案彻底失败——挡住了输入框。

A

欢迎语作为 Chatbot 第一条消息（推荐）

欢迎语直接放在 Chatbot 的 value 里：[{"role": "assistant", "content": welcome_html}]。学生发消息后，chat_history 正常追加。Chatbot 使用 justify-content: center 在只有一条消息时居中，多条消息时从顶部开始。

优点：不需要 overlay、不需要 z-index、不需要 DOM 操作。Gradio 原生支持。上次修复验证可行。
缺点：欢迎语和真实消息在同一个容器里，CSS 需要用 :only-child 或 :has() 区分居中/顶对齐。

B

CSS :has() 控制可见性

欢迎区是一个独立的 div，放在 Chatbot 上方。用 CSS .chat-area:has(.message) ~ #welcome { display: none } 在有消息时自动隐藏。

优点：欢迎区和对话区物理分离，CSS 更干净。
缺点：Gradio 的 Svelte 渲染 DOM 结构不可控，:has() 选择器可能找不到正确的元素。上次 overlay 方案就是因此失败的。
