# 基于 RAG 的大学课程学习助手

本项目是一个基于 **RAG（Retrieval-Augmented Generation，检索增强生成）** 技术的大学课程学习助手，面向高校学生的课程学习、复习与考试准备场景。  
用户可以上传课程 PDF 教材、课件与讲义，系统会自动完成文本提取、分块、向量化、检索与生成，从而提供可追溯、可复核的智能学习支持。

系统的目标不是替代教材，而是帮助用户更高效地理解课程内容、整理知识结构、生成复习提纲，并在学习过程中形成可持续积累的个人课程知识库。

---

## 核心功能

### 1. 课程资料管理
- 支持创建课程分类，例如“数据结构”“计算机网络”等。
- 支持向指定课程上传 PDF 格式教材或课件。
- 自动对 PDF 执行文本提取、智能分段（Chunk）、向量化（Embedding）和索引存储。
- 支持查看课程内文件列表。
- 支持删除单个文件或删除整个课程，便于灵活维护学习资料。

### 2. 智能问答
- 用户可基于自然语言直接提问。
- 系统先通过语义检索从课程资料中召回最相关的文本片段。
- 再将检索结果与问题共同送入大语言模型生成答案。
- 回答中会标注引用来源，例如文件名、章节或页码，增强可追溯性。
- 当资料中找不到相关内容时，系统会明确提示，而不会凭空生成答案。

### 3. 课程总结
- 支持使用 `/总结` 命令自动生成指定课程的整体总结。
- 内容包括：
  - 课程概览
  - 核心知识点列表（5–10 个）
  - 重点章节分析
  - 高频考点
  - 推荐学习路线
  - 复习顺序建议
- 总结内容严格基于已上传课程资料，尽量避免无关内容或“幻觉”输出。

### 4. 章节总结
- 用户可指定章节名称，例如“红黑树”“第三章”。
- 系统将检索与该章节相关的内容并生成详细总结。
- 总结通常包括：
  - 章节简介
  - 重点知识（3–6 个）
  - 难点知识（1–3 个）
  - 考试常考内容
  - 关键术语（5–10 个）

### 5. 复习提纲
- 系统可根据课程资料自动生成考前复习提纲。
- 提纲按重要程度分为：
  - 一级重点：必考 / 高频
  - 二级重点：常考 / 可能考
- 每项可标注掌握要求与预计复习时间。
- 同时给出推荐复习顺序和考前冲刺建议，便于快速备考。

### 6. 自动出题
- 支持生成三类题目：
  - 选择题（4 个选项）
  - 判断题
  - 简答题
- 用户可指定：
  - 出题数量（1–20 道）
  - 题型（混合 / 选择题 / 判断题 / 简答题）
  - 知识点范围（全部课程或指定章节）
- 每道题包含题目、正确答案、解析和来源章节。
- 题目难度适中，适合大学课程期末考试训练。
- 同时支持自然语言出题，例如“再出 5 道关于 B 树的题”。

### 7. 知识点解释
- 支持使用 `/解释` 命令指定一个知识点进行说明。
- 解释方式遵循“由浅入深、举例优先、善用类比”的原则。
- 提供三种解释风格：
  - 通俗（默认）
  - 学术
  - 应试
- 解释过程中会区分：
  - 来自课程资料的内容
  - 来自补充知识的内容

### 8. 学习记录
- 系统自动记录用户的每次提问与回答。
- 记录内容包括：
  - 时间戳
  - 课程
  - 问题
  - 回答
  - 引用来源
- 用户可通过 `/历史` 命令查看学习记录，并按课程筛选，方便回顾和复习。

### 9. Web 交互界面
- 提供基于 **Gradio** 的 Web 图形界面。
- 左侧为课程管理与资料上传区域。
- 右侧为问答对话区域。
- 支持流式输出，回答可逐步显示，提升交互体验。
- 同时保留 CLI 命令行模式，适用于不同使用环境。

---

## 项目特点

- 基于 RAG 架构，强调“先检索，再生成”。
- 面向大学课程场景，适合教材、课件、讲义等资料。
- 支持问答、总结、复习、出题、解释等多种学习任务。
- 回答带来源，提升可解释性与可追踪性。
- 支持 Web 和 CLI 两种使用方式。

---


## 命令使用指南

系统内置了一组斜杠命令（Slash Commands），用户无需复杂配置即可快速调用各类学习辅助功能。

| 命令 | 功能 | 示例 |
|--------|--------|--------|
| `/总结` | 生成课程整体总结 | `/总结 数据结构` |
| `/章节 名称` | 生成指定章节总结 | `/章节 红黑树` |
| `/复习` | 生成考前复习提纲 | `/复习` |
| `/出题 类型 数量` | 自动生成练习题 | `/出题 选择 5` |
| `/解释 知识点` | 解释指定知识点 | `/解释 TCP三次握手` |
| `/历史` | 查看学习记录 | `/历史` |
| `/帮助` | 查看命令帮助信息 | `/帮助` |
