# ChatGPT 风格三区布局重构

> 2026-06-08 | 决策者: yutao

## 目标

将当前"展示型单栏"布局重构为 ChatGPT / Claude 风格的"输入驱动型"三区布局，让用户打开页面后 1 秒看到输入框、2 秒理解功能、3 秒开始使用。

## 核心决策

| 决策 | 选择 |
|------|------|
| 布局模式 | 侧边栏 + 主内容 + 底部输入区（三区） |
| 侧边栏风格 | Claude 风格（课程为一级组织单元，点击即切换） |
| 底部输入区 | 极简（大输入框 + 发送按钮，无快捷按钮行） |
| 品牌色 | #10a37f（仅主按钮/链接/聚焦态） |
| UI 框架 | 保持 Gradio，通过自定义 CSS 实现布局 |

---

## 一、页面布局

```
+----------+------------------------------------+
|          |                                    |
|  侧边栏   |          主内容区                    |
|  260px   |          max-width: 768px           |
|          |          居中，超宽屏大量留白          |
|  Logo    |                                    |
|  新建课程 |          对话气泡                    |
|  课程列表 |          Markdown 渲染               |
|  上传    |          折叠来源                     |
|  设置    |                                    |
|          +------------------------------------+
|          |  +------------------------------+  |
|          |  |  输入框（14px 大圆角，细边框）  |  |
|          |  |                     [发送]   |  |
|          |  +------------------------------+  |
+----------+------------------------------------+
```

### 视觉重心

- 70% 主内容区（对话）
- 20% 底部输入区
- 10% 侧边栏

## 二、设计系统

### 颜色

| 用途 | 色值 | 说明 |
|------|------|------|
| 品牌色 | `#10a37f` | 仅主按钮背景、链接色、聚焦边框 |
| 主文字 | `#0d0d0d` | 标题、正文 |
| 次文字 | `#6b6b6b` | 辅助说明、来源标注 |
| 辅文字 | `#9e9e9e` | 标签、占位符、时间戳 |
| 主背景 | `#ffffff` | 主内容区、输入框 |
| 次背景 | `#f7f7f8` | 侧边栏、用户气泡、代码块 |
| 边框 | `#e5e5e5` | 默认分隔 |
| 浅边框 | `#f0f0f0` | 输入框内部、细微分隔 |

### 字体

```
font-family: -apple-system, BlinkMacSystemFont, "Segoe UI",
             Roboto, "Helvetica Neue", Arial,
             "PingFang SC", "Microsoft YaHei", sans-serif
```

层级仅靠字号 + 字重，不依赖颜色：
- 标题: 18-20px / weight 700
- 正文: 15px / weight 400
- 辅助: 13px / weight 400
- 标签: 11-12px / weight 500

### 禁止项

- 渐变背景
- 玻璃拟态 (Glassmorphism)
- 霓虹色
- 动画 / 过渡
- 卡片阴影（box-shadow: none，仅输入框保留 1px 微弱阴影）
- emoji 图标

### 圆角

- 常规: 6-8px
- 输入框: 14px（大圆角，区分于其他元素）

## 三、侧边栏设计

### 结构

```
+-------------------+
| Logo / 标题        |
| [+ 新建课程]       |
|                   |
| 课程列表           |
| - 操作系统 (当前)   |
| - 数据结构         |
| - 计算机网络       |
|                   |
|                   |
| ─────────         |
| 上传资料           |
| 设置              |
+-------------------+
```

- 宽度固定 260px
- 背景 #f7f7f8，右侧 1px 边框分隔
- 当前课程高亮显示（背景 #e8e8ea）
- 点击课程名即时切换，对话区刷新为对应课程上下文

---

## 四、底部输入区

- 宽度与主内容区一致（max-width: 768px）
- 大圆角 14px，1px 细边框 #e5e5e5
- 仅包含：输入框 + 发送按钮
- 快捷操作（出题、标记薄弱点）通过斜杠命令触发，不在 UI 上显示
- Enter 发送，Shift+Enter 换行

---

## 五、功能映射

| 区域 | 包含功能 |
|------|---------|
| 左侧边栏 | Logo、新建课程、课程列表、上传资料、设置 |
| 主内容区 | 欢迎消息、对话气泡、Markdown 渲染、折叠来源 |
| 底部输入 | 输入框、发送按钮、斜杠命令（隐藏） |

### 移除的 UI 元素

| 旧元素 | 去向 |
|--------|------|
| 顶部工具栏（课程下拉、新建、上传、删除） | 移入侧边栏 |
| 快捷按钮行（出题、薄弱点、清空） | 删除，改为斜杠命令 |
| 状态消息区（top_msg） | 合并入欢迎消息 |
| 删除课程按钮 | 移入侧边栏底部 |
| emoji 图标 | 全部移除 |

## 六、技术实现

### Gradio 适配

- 使用 `gr.Row()` 实现侧边栏 + 主内容双栏
- 侧边栏通过 CSS `position: fixed` 固定在左侧
- 主内容通过 `max-width: 768px; margin: 0 auto` 居中
- 输入区通过 flexbox 固定在底部
- 主题和 CSS 通过 `demo.launch(css=..., theme=...)` 注入（Gradio 6.x API）

### CSS 关键点

```css
.gradio-container { max-width: none !important; padding: 0 !important; }
.sidebar { position: fixed; left: 0; top: 0; width: 260px; height: 100vh; }
.main-area { margin-left: 260px; display: flex; flex-direction: column; height: 100vh; }
.composer { max-width: 768px; margin: 0 auto; width: 100%; }
```

### 风险

- Gradio 6.x 的 DOM 结构可能与 CSS 假设冲突，需要实测调试
- 侧边栏固定定位可能与 Gradio 的容器包裹产生 z-index 问题
- 响应式：移动端侧边栏需折叠为汉堡菜单（后续迭代）

---

## 七、不做的事情

- 不引入新前端框架（保持 Gradio）
- 不添加深色模式（保持亮色）
- 不做响应式移动端适配（桌面优先）
- 不添加对话历史/会话管理（保持课程级上下文持久化）
- 不在侧边栏显示对话历史列表
